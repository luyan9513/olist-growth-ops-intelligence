# 指标字典

本文件是业务口径的快速索引；详细分母、异常处理和边界见 `01_requirements_and_metrics.md`。

| ID | 指标 | 公式 | 默认粒度 | 主要来源 | 关键边界 |
|---|---|---|---|---|---|
| M-01 | 有效 MQL 数 | `count(distinct mql_id)` | 首次接触月×来源 | MQL | 主键与首次接触有效 |
| M-02 | 成交率 | 合法成交 MQL / 有效 MQL | 首次接触月×来源 | MQL、成交 | 按首次接触归属；非因果 |
| M-03 | 已交付 GMV | `sum(price + freight_value)` | 商家×月 | 订单、商品 | 仅已交付；不是收入/利润 |
| M-04 | 订单数 | `count(distinct order_id)` | 主题定义粒度 | 订单 | 平台订单与卖家订单区分 |
| M-05 | 客单价 | GMV / 对应订单数 | 商家/渠道×月 | mart | 分母 0 返回空 |
| M-06 | 延迟率 | 延迟订单 / 可判断已签收订单 | 商家/品类/地区×月 | 订单 | 使用原始时间戳；缺失不入分母 |
| M-07 | 低评分率 | 评分≤2订单 / 合法有评订单 | 商家/品类/地区×月 | 评价、订单 | 多评价取最新合法记录 |
| M-08 | 取消率 | canceled 订单 / 有效订单 | 月/商家/渠道 | 订单 | unavailable 单列 |
| M-09 | Precision@K | Top-K 正例 / K | 模型测试集 | 预测结果 | 输出实际 K 与阈值 |
| M-10 | Recall@K | Top-K 正例 / 全部正例 | 模型测试集 | 预测结果 | 与 Precision 同时报 |
| M-11 | Lift@K | Precision@K / 整体正例率 | 模型测试集 | 预测结果 | 仅离线排序解释 |
| M-12 | PR-AUC | PR 曲线下面积 | 模型测试集 | 预测结果 | 适合不平衡分类 |
| M-13 | WAPE | 绝对误差和 / 真实绝对值和 | 回测窗口/实体 | 预测结果 | 分母 0 窗口不计算 |
| M-14 | MAE | 平均绝对误差 | 回测窗口/实体 | 预测结果 | 与 WAPE 配套 |
| M-15 | 商家周活动率 | 订单量>0的商家周 / 全部回测商家周 | 回测周/活动层 | 预测结果 | 实体从首次出现周开始；不是全市场商家活跃率 |
| M-16 | Brier score | 概率预测与二元标签的均方误差 | 活动回测窗口 | 预测结果 | 越低越好；与训练活动率概率基线比较 |
| M-17 | 两阶段期望订单量 | 活动概率 × 活跃条件订单量 | 商家×预测周 | 预测结果 | 仅离线资源排序，不是库存承诺 |
| M-18 | 活动概率质量覆盖 | 选中商家活动概率和 / 可评分商家活动概率和 | 当前筛选×容量 | 行动清单 | 模型质量覆盖，不是实际活跃覆盖 |
| M-19 | 期望订单量覆盖 | 选中商家期望订单量和 / 可评分商家期望订单量和 | 当前筛选×容量 | 行动清单 | 非增量订单 |
| M-20 | 近期 GMV 覆盖 | 选中商家最近 13 周 GMV / 可评分商家最近 13 周 GMV | 当前筛选×容量 | 行动清单 | 历史暴露，不是未来收益 |
| M-21 | 高价值高风险覆盖 | 选中高价值高风险商家数 / 可评分高价值高风险商家数 | 当前筛选×容量 | 行动清单 | 无活动分数商家仍保留在风险页 |
| M-22 | 规划总样本量 | 两独立比例双侧正态近似；按分流比例拆组 | 实验设计 | 规划参数 | MDE 是假设，不是预计效果；非均匀分流为效率近似 |
| M-23 | 当前池可检测 MDE | 给定候选量反解可检测绝对比例变化 | 实验设计 | P10 资格快照 | 未包含成熟率、聚类和流失膨胀 |
| M-24 | 实验执行率 | 至少一次成功执行的处理组分组 / 处理组分组 | 实验×观察期 | 分组、执行日志 | 过程指标；不替代 ITT |
| M-25 | 结果成熟率 | 完整观察窗结果分组 / 全部分组 | 实验×观察期 | 分组、结果日志 | 未成熟不记为 0 |
| M-26 | 实验低评分率 | 低评分订单 / 合法评价订单 | 实验×组别×观察窗 | 结果日志 | 分母 0 为空；需报告组间差与区间 |

## 统一展示规则

- 比率内部保留完整精度，展示时统一转成百分比；
- 金额以数据原始币种展示，若源数据未明确币种则标注“数据集金额单位”，不擅自换汇；
- 所有 KPI 同时展示数据时间范围、样本量和必要的缺失率；
- 无真实成本时不展示 ROI；无实验时不展示“提升了 X%”类因果措辞。
