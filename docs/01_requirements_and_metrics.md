## 3. KPI 框架

核心结果指标选择 3 个，分别覆盖增长、经营和体验；其余作为诊断或护栏。

| 层级 | 指标 | 业务含义 | 主要决策 |
|---|---|---|---|
| 核心 KPI | 成交率 | 有效线索进入成交的比例 | 渠道复盘与触达分配 |
| 核心 KPI | 已交付 GMV | 成交商家在有效已交付订单上的交易规模代理 | 商家价值分层 |
| 核心 KPI | 低评分率 | 有评价订单中严重负向体验的比例 | 风险干预优先级 |
| 驱动指标 | MQL 数、成交数、成交商家数 | 区分流量、转化与实体覆盖 | 漏斗诊断 |
| 驱动指标 | 订单数、活跃商家数、客单价 | 拆解 GMV 变化 | 经营诊断 |
| 驱动指标 | 延迟率、承诺窗口、履约时长 | 拆解体验风险 | 履约诊断 |
| 护栏指标 | 取消率、无法关联率 | 防止只看已交付订单造成选择偏差 | 数据/业务质量 |
| 护栏指标 | Top-K 精确率与召回率同时报告 | 防止排序只追求覆盖或只追求命中 | 运营容量决策 |

当前不设业务提升目标，因为没有真实运营基线、成本和实验。项目验收目标是“口径完整、流程可运行、模型与基线可比较”，模型阈值和业务目标只能在实际结果产生后提出。

## 4. 指标详细定义

### M-01 有效 MQL 数

- 粒度：线索首次接触月 × 来源；
- 计算：`count(distinct mql_id)`；
- 纳入：`mql_id`、`first_contact_date` 均有效的记录；
- 排除：重复主键保留规则尚未确认前不自动去重，先作为质量异常；
- 来源：marketing qualified leads staging 表。

### M-02 成交数与成交率

- 成交标签：同一有效 `mql_id` 存在非空且不早于首次接触时间的 `won_date`；
- 成交数：成交标签为 1 的唯一 MQL 数；
- 成交率：成交数 / 有效 MQL 数；分母为 0 时返回空值而非 0；
- 时间归属：默认按首次接触月归属，另保留成交月用于周期分析；
- 限制：描述历史相关性，不代表渠道因果增量。

### M-03 已交付 GMV

- 粒度：订单/商家/月，最终可汇总；
- 计算：已交付订单中 `sum(item_price + freight_value)`；
- 一笔多商品订单先在订单商品粒度汇总，避免与支付、评价表多对多连接重复；
- 取消、不可用、未发货等订单不进入主 GMV，单独计算状态金额；
- 不等同于收入、净销售额、利润或支付额。

### M-04 订单数与客单价

- 订单数：满足对应状态过滤的唯一 `order_id` 数；
- 客单价：GMV / 对应订单数；分母为 0 时为空；
- 订单包含多个卖家时，卖家分析采用“卖家-订单”粒度，跨卖家汇总不可直接相加为平台订单数。

### M-05 延迟率

- 适用集合：实际签收时间与预计送达时间均有效的已签收订单；
- 延迟标记：`order_delivered_customer_date > order_estimated_delivery_date`；
- 延迟率：延迟订单数 / 可判断延迟的已签收订单数；
- 同一天内的时间差按原始时间戳比较，不用日期截断；
- 缺失实际或预计时间的订单不进入分母，并单独报告缺失率。

### M-06 低评分率

- 低评分：聚合到订单级的代表评分 `<= 2`；
- 适用集合：存在 1–5 合法评分的唯一订单；
- 低评分率：低评分订单数 / 有合法评价订单数；
- 多评价订单需保留可复现聚合规则，默认使用最新创建时间的合法评价，并报告多评价异常；
- 不能推断延迟导致低评分。

### M-07 取消率

- 取消订单数 / 有效订单数；
- `canceled` 为取消，`unavailable` 单独展示，不混入取消；
- 用作 GMV 和履约分析的选择偏差护栏。

### M-08 线索 Top-K 指标

- K：测试集预测分数前 20%，并支持运营容量对应的绝对 K；
- Precision@K：Top-K 中真实成交数 / K；
- Recall@K：Top-K 中真实成交数 / 测试集全部真实成交数；
- Lift@K：Precision@K / 测试集整体成交率；
- 并列分数按稳定次序处理，实际纳入数和阈值必须输出。

### M-09 低评分风险 Top-K 指标

- Precision@K：Top-K 风险订单中真实低评分订单占比；
- Recall@K：Top-K 覆盖的真实低评分订单 / 测试集全部低评分订单；
- 同时输出 PR-AUC、校准曲线和 Brier score，避免只看排序不看概率可靠性。

### M-09A 分类模型稳健性指标

- 滚动时间回测：使用至少 3 个连续评估窗口，每个窗口只用其之前的数据训练；报告每窗 PR-AUC、Brier、Top 10%/20% Lift，以及均值、标准差和最差窗口；
- bootstrap 区间：在最终测试窗按样本有放回抽样，固定随机种子，报告 PR-AUC、Brier 和 Top 20% 指标的 95% 百分位区间；若某次抽样只有单一标签则跳过并记录有效次数；
- 概率校准：基础模型拟合数据、选模数据、校准数据和最终测试数据按时间隔离；校准方法及所用样本数写入结果文件；
- 复杂模型增益：同时报告相对先验基线和逻辑回归的绝对差值，不能只选择对复杂模型有利的基线；
- 接受标准：只有在多个时间窗多数胜出、最差窗口没有明显失效且 Top-K 与校准至少一项获得可复现改善时，才称为“稳定提升”；否则记录为“未证明稳定提升”。

### M-10 需求预测误差

- 主指标：WAPE = `sum(abs(y - yhat)) / sum(abs(y))`；分母为 0 的回测窗口不计算；
- 辅助：MAE；对间歇需求另报非零周覆盖、逐周 WAPE/胜负和分层表现；
- 各模型必须使用相同滚动窗口，不能用未来值补齐滞后特征。

### M-10A 商家两阶段间歇需求指标

- 第一阶段标签：商家在预测周订单量是否大于 0；主指标为 PR-AUC，辅助指标为 Brier score，并与训练窗活动率形成的常数概率基线比较；
- 第二阶段目标：仅在训练窗真实订单量大于 0 的样本上学习条件订单量；最终期望订单量为“活动概率 × 条件订单量预测”，不把 0.5 阈值硬分类当作唯一产量预测；
- 间歇需求基线：Croston-SBA，只使用预测周之前的非零需求量与非零间隔；同时保留 4 周移动平均、季节朴素和直接 Poisson 梯度提升；
- 活动层：按预测周之前 13 周的活跃周数划分。`7–13` 周为“持续活跃”，`2–6` 周为“间歇活跃”，`0–1` 周为“长尾/沉默”；阈值在开发前固定，不根据测试结果改写；
- 稳定性：报告 8 个连续测试周中，两阶段期望订单量相对 4 周移动平均和直接回归的 WAPE 胜出周数；聚合 WAPE 改善但多数周不胜出时，只写“聚合误差改善”，不写“稳定提升”；
- 接受规则：只有聚合 WAPE 优于 4 周移动平均、8 周中至少 5 周不劣于移动平均，且活动 PR-AUC高于测试期活动率，才把两阶段期望订单量列为商家主模型；否则商家交付降级为活动概率和历史活动层，品类预测仍为主需求预测。

### M-10B 商家行动清单容量覆盖

- 适用集合：具有下一周活动概率且可连接商家风险表的唯一商家；无需求历史的商家不补造概率，仍保留在独立风险清单；
- 行动规则：先按“高价值高风险且活动不低”“高价值高增长且高活动”“体验风险且活动不低”“高价值且高活动”“常规观察”生成互斥行动类型，再按行动优先级、活动概率、历史已交付 GMV和商家 ID稳定排序；
- 活动档位阈值：在当前评分快照内计算活动概率中位数与 75 分位数，写入元数据；阈值不得根据某个容量场景临时变化；
- 预测活动质量覆盖：选中商家活动概率之和 / 全部可评分商家活动概率之和，仅代表模型概率质量覆盖，不是实际活跃商家覆盖；
- 期望订单量覆盖：选中商家期望订单量之和 / 全部可评分商家期望订单量之和，仅用于离线排期参考；
- 近期 GMV 覆盖：选中商家最近 13 周历史 GMV / 全部可评分商家最近 13 周历史 GMV；
- 高价值高风险覆盖：选中高价值高风险商家数 / 全部可评分高价值高风险商家数；
- 对照策略：同一容量额外比较“仅按活动概率”和“仅按最近 13 周 GMV”排序，展示统一行动规则在活动、价值与风险覆盖之间的取舍；对照只用于解释，不根据结果事后改规则；
- 所有容量结果标注为公开历史数据和离线预测快照，不计算增量订单、风险减少、利润或 ROI。

### M-10C 实验规划与运行质量

- 规划样本量：两个独立比例的双侧正态近似，输入基线率、绝对 MDE、风险降低/增长提高方向、alpha、power 和分流比例，分别输出处理组、对照组和总样本；MDE 是设计假设，不是预计效果；
- 可检测变化：给定各组可用样本，反解可检测的最小绝对百分点变化，用于判断当前候选池能否支撑目标精度；
- 分组平衡：按干预前的行动类型、活动档位和州对比处理/对照数量与占比；小样本不平衡必须披露，不事后重分配；
- 执行率：实际至少一次成功执行的唯一分组数 / 处理组分组数；只作为过程指标，不用于替代 ITT 主分析；
- 结果成熟率：已有完整观察窗结果的唯一分组数 / 全部分组数；未成熟样本不得当作 0；
- 主指标：处理组与对照组各自的低评分订单数 / 合法评价订单数，报告绝对差、相对差和区间；分母为 0 时为空；
- 护栏：延迟率、取消率、退款金额、评价覆盖率和单分组成本；所有金额必须带币种，不根据缺失成本计算 ROI。

## 5. 看板验收

| 页面 | 最小验收 |
|---|---|
| 增长总览 | 日期/来源筛选同步作用于 KPI 和趋势；成交率分母可追溯 |

## 6. 结果发布门槛

- 数据文件和许可核验完成；
- `dbt build`、Python 测试和模型泄漏检查通过；
- 分类模型稳健性产物包含滚动窗口、bootstrap 区间、校准集边界和原始/校准后对比；
- 报告中的每个量化结论均有结果文件或查询证据；
- 结果时间范围、样本量和缺失/关联损失同时披露；
- 未运行的数据结果使用“待运行/待验证”，不得填入估算值。

## 7. P9 商家间歇需求真实执行结果

- 测试集 23,268 个商家周，实际活跃 5,010 个，活动率 21.53%；活动分类 PR-AUC 0.680、Brier 0.111，8 个单周 PR-AUC 0.628–0.743，均高于当周活动率；
