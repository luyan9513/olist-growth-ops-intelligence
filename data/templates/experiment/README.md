# 实验日志空模板

本目录提供 P11 数据契约的表头模板，不包含示例行，也不代表实验已启动。

- `experiment_registry.csv`：实验假设、资格、指标、时间与状态；
- `assignment_log.csv`：资格快照和不可变随机分组；
- `execution_log.csv`：真实运营执行尝试、状态与成本；
- `outcome_log.csv`：观察窗成熟后的指标分子、分母和金额。

真实接入时应将文件复制到受控数据区，补充访问权限、保留策略和负责人。不要在公开仓库写入姓名、电话、邮箱、聊天文本、密钥或内部商家标识；操作人字段只能使用已批准的去标识化 ID。
